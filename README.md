# বাংলাদেশ ক্রনিকল (Bangladesh Chronicle) — সম্পূর্ণ অটোমেটেড নিউজ পোর্টাল

আগের ভার্সনে `auto_fetch_news.js` একটা **fake** খবরের তালিকা থেকে র‍্যান্ডম খবর বসাতো —
সেটা আসল খবর ছিল না। এই ভার্সনে পুরো সিস্টেমটা বদলে দেওয়া হয়েছে:

## এখন যেভাবে কাজ করে

1. **`scripts/fetch-news.mjs`** — বাংলাদেশের প্রধান সংবাদমাধ্যমগুলোর (প্রথম আলো, ডেইলি
   স্টার, বাংলা নিউজ ২৪, যুগান্তর, জাগো নিউজ, কালের কণ্ঠ, বিডিনিউজ২৪, বিবিসি বাংলা...)
   **আসল RSS ফিড** থেকে সরাসরি খবর টেনে আনে, ক্যাটাগরি অনুযায়ী সাজায় (জাতীয়, রাজনীতি,
   আন্তর্জাতিক, অর্থনীতি, খেলাধুলা, বিনোদন, প্রযুক্তি, শিক্ষা, স্বাস্থ্য, মতামত), এবং
   `data/news.json` ফাইলে লিখে রাখে।
2. **`.github/workflows/update-news.yml`** — GitHub Actions ব্যবহার করে প্রতি ২০ মিনিটে
   ওই স্ক্রিপ্টটা নিজে নিজে চালায় এবং নতুন খবর থাকলে সরাসরি রিপোজিটরিতে commit করে push
   করে দেয়। **কোনো সার্ভার, কোনো টাকা খরচ, কোনো ম্যানুয়াল কাজ লাগবে না** — এটা GitHub-এর
   নিজস্ব ফ্রি ইনফ্রাস্ট্রাকচারে চলে।
3. **`index.html`** — স্ট্যাটিক পেজ, যেটা `data/news.json` থেকে খবর লোড করে দেখায়। কোনো
   হার্ডকোড করা fake খবর নেই।

স্ক্রিপ্টে **কোনো npm প্যাকেজ ব্যবহার করা হয়নি** (শুধু Node.js-এর built-in `https`/`fs`) —
তাই `npm install` কখনো লাগবে না, আর কোনো প্যাকেজ ভেঙে গিয়ে সিস্টেম বন্ধ হয়ে যাওয়ার ঝুঁকি
নেই। কোনো একটা সোর্স বন্ধ হয়ে গেলে বা ফরম্যাট বদলালে, শুধু সেই সোর্সটা স্কিপ হয়ে যাবে —
বাকি সোর্সগুলো থেকে খবর আসতেই থাকবে।

## একবার সেটআপ করলেই চলবে — পরে আর কিছু করতে হবে না

1. এই পুরো রিপোজিটরি GitHub-এ push করুন।
2. GitHub-এ রিপোর **Settings → Actions → General → Workflow permissions**-এ গিয়ে
   **"Read and write permissions"** সিলেক্ট করে Save করুন (এটা একবারই করতে হয়, যাতে
   workflow নিজে থেকে commit/push করার অনুমতি পায়)।
3. **Settings → Pages**-এ গিয়ে "Deploy from a branch" সিলেক্ট করে `main` ব্রাঞ্চ থেকে
   সাইট পাবলিশ করুন (অথবা আপনার পছন্দের যেকোনো স্ট্যাটিক হোস্টিং — Netlify/Vercel-এও কাজ
   করবে)।
4. **Actions** ট্যাবে গিয়ে "Update Bangladesh News" workflow-টা একবার ম্যানুয়ালি Run
   করে দিন (Run workflow বাটনে ক্লিক করে) — এতে প্রথমবার `data/news.json` পূরণ হয়ে
   যাবে। এরপর থেকে এটা প্রতি ২০ মিনিটে নিজে থেকেই চলবে।

ব্যস — এরপর থেকে সাইটটা নিজে নিজেই আপডেট হতে থাকবে। কোনো নির্দিষ্ট মেয়াদ নেই — যতদিন
GitHub Actions ফ্রি থাকবে (এবং আছেও অনেক বছর ধরে), ততদিন এটা চলবে। ২ বছর কেন, তার চেয়ে
বেশি সময়ও কোনো আপডেট ছাড়াই চলার কথা।

## জেনে রাখা ভালো (সীমাবদ্ধতা)

- **এটা মূলত একটা নিউজ অ্যাগ্রিগেটর/ইনডেক্স** — প্রতিটা খবরের টাইটেল, ছোট সারাংশ এবং
  ছবি দেখায়, কিন্তু পুরো আর্টিকেল কপি করে না (কপিরাইট আইন অনুযায়ী এটাই সঠিক পদ্ধতি)।
  পুরো খবর পড়তে ইউজারকে মূল সংবাদমাধ্যমের লিংকে ক্লিক করতে হবে।
- খবরের মূল কনটেন্ট যে ভাষায় প্রকাশিত হয়েছে (বাংলা বা ইংরেজি সোর্স থেকে) সেই ভাষাতেই
  থাকবে — সাইটের বাটন-মেনু বাংলা/ইংরেজি টগল করলেও পুরনো খবর অটো-ট্রান্সলেট হবে না
  (ভুল অনুবাদ এড়াতে ইচ্ছাকৃতভাবে এটা যোগ করা হয়নি)।
- `data/news.json` সময়ের সাথে বড় হতে থাকবে — সাইটের গতি ঠিক রাখতে স্ক্রিপ্টে সর্বশেষ
  ৮০০টা খবর রাখার একটা সীমা রাখা হয়েছে (`MAX_ITEMS`), চাইলে `scripts/fetch-news.mjs`
  ফাইলে গিয়ে সংখ্যাটা বাড়ানো/কমানো যাবে।
- লোকালি `index.html` ফাইলটা সরাসরি ব্রাউজারে ডাবল-ক্লিক করে খুললে `fetch()` কাজ নাও
  করতে পারে (ব্রাউজার সিকিউরিটি পলিসি) — টেস্ট করতে চাইলে লোকাল সার্ভার চালান, যেমন:
  `python3 -m http.server` অথবা GitHub Pages-এ পাবলিশ করে দেখুন।
