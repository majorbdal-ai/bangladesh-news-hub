> **"Bangladesh News Hub"** হলো একটি সম্পূর্ণ অটোমেটেড, রিয়েল-টাইম এবং আধুনিক বাংলা নিউজ অ্যাগ্রিগেটর প্ল্যাটফর্ম। দেশের শীর্ষস্থানীয় সংবাদমাধ্যমগুলোর নির্ভরযোগ্য RSS ফিড থেকে সরাসরি রিয়েল-টাইম নিউজ সংগ্রহ করে ক্যাটাগরি অনুযায়ী সাজিয়ে প্রদর্শন করে। কোনো ধরনের বিজ্ঞাপন বা এক্সটার্নাল থার্ড-পার্টি ব্র্যান্ডিং ছাড়াই সম্পূর্ণ পরিচ্ছন্ন ইউজার ইন্টারফেসে সংবাদ পড়ার দারুণ অভিজ্ঞতা দেয়।

## 🎖️ প্রধান বৈশিষ্ট্যসমূহ (Key Features)

### ১. 🔄 অটোমেটেড রিয়েল-টাইম সিংক (24/7 Automation)
- **GitHub Actions CI/CD:** ব্যাকগ্রাউন্ড সার্ভারের মাধ্যমে প্রতি ৫ মিনিট পর পর নিজে থেকেই নতুন সংবাদ ফেচ করে এবং সাইট আপডেট করে। কোনো ম্যানুয়াল কাজের প্রয়োজন নেই।

### ২. 📑 নিখুঁত ক্যাটাগরি ম্যানেজমেন্ট (Category Organization)
- জাতীয়, রাজনীতি, অর্থনীতি ও ব্যবসা, খেলাধুলা, প্রযুক্তি, বিনোদন, শিক্ষা, স্বাস্থ্য এবং আন্তর্জাতিক—এই ক্যাটাগরিগুলোতে স্বয়ংক্রিয়ভাবে খবর সাজানো হয়।

### ৩. 🛡️ প্রাইভেসি ও স্যানিটাইজেশন (Clean Content)
- অন্য কোনো ওয়েবসাইটের এক্সটার্নাল ব্র্যান্ডিং বা নাম ছাড়াই সম্পূর্ণ পরিচ্ছন্ন ও নিজস্ব ব্র্যান্ডিংয়ে সংবাদ পরিবেশিত হয়। ব্যবহারকারীরা সাইটের ভেতরেই পপআপ মডালে সম্পূর্ণ খবর পড়তে পারেন।

### ৪. 🚫 ডুপ্লিকেট ও ইমেজ প্রটেকশন (Duplicate & Image Shield)
- একই ছবি বা নিউজের পুনরাবৃত্তি রোধে উন্নত ডুপ্লিকেসি ফিল্টারিং এবং সাত দিনের ইমেজ প্রুনিং সিস্টেম (`used-images.json`) যুক্ত রয়েছে।

### ৫. ⚡ লাইটওয়েট ও ফাস্ট (Performance)
- কোনো ভারী থার্ড-পার্টি লাইব্রেরি বা জটিল ডেটাবেজ ছাড়াই Node.js এবং Tailwind CSS-এর মাধ্যমে তৈরি, ফলে লোডিং স্পিড অত্যন্ত দ্রুত।

## 🛠️ প্রযুক্তিগত কাঠামো (Tech Stack)

- **Frontend:** HTML5, Tailwind CSS v2.2, Alpine.js v3, FontAwesome.
- **Backend Automation:** Node.js (Built-in `https`, `fs`, `url` modules - zero external npm overhead).
- **Hosting & CI/CD:** GitHub Pages & GitHub Actions (24/7 Autonomous Sync).
